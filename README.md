# FlowForge ETL

FlowForge ETL is a configurable and extensible ETL platform built with Java 21 and Maven.

## Goals

- Modular and extensible architecture.
- Configurable ETL pipelines.
- Separation of extraction, transformation, and loading.
- Automated testing.
- Support for Microsoft SQL Server as a target.

## Technology Stack

- Java 21
- Apache Maven
- Spring Boot (planned)
- Microsoft SQL Server (planned)
- JUnit (planned)

## Getting Started

Validate the project:

    mvn validate

Build the project:

    mvn clean verify

## Project Status

The project is in its initial setup phase.
